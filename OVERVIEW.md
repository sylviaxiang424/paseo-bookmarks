Bookmark questions, answers, individual command executions, tool results and images in Paseo. The right-hand Bookmarks panel shows excerpts in conversation order, with actions to jump to the original message or remove a bookmark. Gold ticks mark bookmarked turns on the left timeline.

Hover over a message to reveal its bookmark icon. Open Bookmarks from the workspace header to view the right panel. Clicking an excerpt loads the original message and briefly highlights the body at its full width. Questions highlight only their bubble. Tool bookmarks expand the owning turn and result details; image bookmarks locate that specific picture. Bookmarks can also be removed directly from the panel.

When forking into a new tab, choose whether to inherit the original conversation's bookmarks. If the source has no bookmarks, the prompt is skipped. Inherited bookmarks retain their source. Closing the source tab does not break them: the plugin reopens the conversation from history. If the conversation was deleted, the excerpt remains and navigation reports that it is unavailable. Removing an inherited bookmark affects only the current conversation.

Requires Paseo 0.15.x on desktop or web. The interface follows Paseo’s language setting, including “System”. English and Simplified Chinese are supported, with English as the fallback. Native mobile clients are not supported. Message controls, timeline marks and precise navigation depend on Paseo's interface structure and may need updates when the host changes. Navigation waits for history and retries once, but inaccessible sources or an incompatible interface can still prevent a jump.

No additional account, token or external tool is required. Bookmarks are saved on the connected daemon host in its local plugin-data directory. Stored data includes message and output identifiers, source information and text excerpts of up to 800 characters. Excerpts are generated locally without an AI service. The plugin does not send data to external services. Uninstalling the plugin leaves the bookmark data file in place.
